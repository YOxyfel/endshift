# ENDSHIFT website

The ENDSHIFT site: home, the free 20-minute ritual, RESET, Batch #001, the build story, the formula shortlist, FAQ, three sourced journal guides, contact, and the legal pages, in English and Bulgarian.

The home page opens on a small game (find the switch and clock out, a different job each day) and then tells one evening as one continuous shot: scrolling moves the camera down the hallway, into the wall calendar, into tonight's bedroom, through the switch and the seven steps of the ritual (each framed like a game's HUD), to lights out, a dream round the RESET bottle in which the day comes apart, and the sun on its label setting. It's drawn in the browser from the same rooms as the game, with ink lines and cross-hatching. The free ritual is a full-screen experience with its own generated soundtrack and a scene per step, ending in five minutes of guided breathing.

It's a static site generated by one small Node script. There's no framework and no runtime dependency (the 3D rooms run on a small WebGL renderer written for this site), and every page works before any JavaScript runs. The drawn rooms are only loaded on pages that show them; without WebGL the panels keep a drawn-in-CSS stand-in and the game skips the 3D rooms.

## Run it

```bash
npm install          # only installs esbuild (minifier); the build works without it
npm run dev          # build + http://localhost:4321, rebuilds when src/ changes
npm run build        # production build → dist/
npm run check        # run the honesty checks on the config, build nothing
npm run fonts        # re-download the self-hosted fonts from Google Fonts (they're already in src/assets/fonts)
npm run og           # draw the share cards, one per page and language (after a build; needs Playwright)
npm run vapid        # make the keys for the phone reminder (docs/REMINDERS.md)
npm run music:check  # check the recommended music links (needs internet)
npm run test:functions  # check the signup, count, confirmation and reminder functions offline
npm run preview      # build with relative links → dist-preview/ (opens from any folder)
```

Requires Node 18.17 or newer.

## What to edit, and where

Almost everything that will change before launch lives in **`src/config/`**. Page templates never hard-code product facts.

| To change… | Edit | Notes |
|---|---|---|
| Product status (concept → preorder → production → in stock) | `site.config.js` → `product.status` | The build refuses `preorder` or `in_stock` until price, checkout, company details, final legal text and a confirmed formula are all set. |
| Price | `product.price` (number, EUR) | `product.targetPriceRange` shows an honest range before the final price, e.g. `"€24–29"`. |
| Founder target and count | `batch.founderGoal`, `batch.founderCount`, `batch.countUpdated` | Before payments, the counter counts founding-list signups and says so. Optional live count: `batch.countEndpoint` (JSON `{"count": 42}`). |
| Production and shipping dates | `batch.productionLeadTime`, `batch.estimatedDispatch`, `batch.goalDeadline` | Shown as "not set yet" until filled. |
| Refund rules | `batch.refund`, `batch.preorderTermsConfirmed` | |
| Founder benefits | `batch.benefits` | Switch on only what you can deliver. The discount is hidden until you set a percentage. |
| Formula | `src/config/formula.js` | Per ingredient: status, dose, NRV %, claims and cautions. Claims stay hidden until `verified: true` **and** `product.formulaConfirmed: true`. |
| Formula final | `site.config.js` → `product.formulaConfirmed` | The build then requires a dose for every ingredient and a serving size. |
| Packaging | `product.packagingFinal` | While `false`, the bottle is labelled "concept render". Replace the render in `components.js → productRender` with photography when you have it. |
| Checkout | `checkout.enabled`, `checkout.url` | Any hosted checkout works (Stripe Payment Link, Shopify, …). |
| Company, manufacturer, shipping | `company.*`, `manufacturer.*`, `shipping.*` | Company details appear in the footer, contact page and legal pages automatically. |
| Build timeline | `src/config/timeline.js` | Status `done` / `now` / `next`, optional date, decision and media link. |
| Reviews | `socialProof.testimonials` | Real ones only. The build rejects entries without `consent: true`, a date and a source. |
| Email capture | `forms.endpoint` | `/api/signup` once the mailing tool is connected (Brevo or MailerLite with double opt-in: `server/core.mjs`, settings via environment variables), or any URL that accepts a JSON POST. Until it's set, forms run in clearly labelled preview mode and send nothing. The emails to paste into the tool are in `docs/EMAILS.md`. |
| Live founder count | `batch.countEndpoint` | `/api/count` reads the confirmed count from the same mailing tool (cached 5 minutes). |
| Analytics | `analytics.provider` | `plausible` or `umami` (cookieless, no banner) or `ga4` (loads only after opt-in). See `docs/ANALYTICS.md`. |
| Copy | `src/content/<lang>/<page>.js` | One file per page per language; shared UI text in `ui.js`. |
| The hero game | `site.config.js` → `game` | On/off, which game on which weekday (`week`), `?job=` links, and the reward (`percent`, `tag`, `expiresDays`, `termsConfirmed`). Words for every game, object, hint and the words on things in the rooms (`props`: tickets, signs, screens): `src/content/<lang>/game.js`. Rooms: `src/assets/js/game-scenes.js` (written in centimetres, against a wall). Play any game with `/?job=bed` (or `kitchen`, `ward`, `office`, `shop`, `clients`, `depot`); `&play` replays one you already won today. |
| The story on the home page | `src/content/<lang>/home.js` → `story` and `story.film` (+ `recog`, `idea`, `ritual` copy; the ritual steps come from `ritual.js`) | Captions, time stamps, sound effects, the calendar, the founder strip (`founder.panels`). The film's beats, lengths and camera moves: `BEATS`, `KH`, `KB` in `src/assets/js/film.js`; its markup: `src/templates/film.js`. Other panels' rooms and cameras: `V` in `src/assets/js/story.js`. |
| Story media | `site.config.js` → `story.media` | Any panel can be swapped for a clip or a still, e.g. `{ hall: '/assets/media/hall.mp4' }`. Full URLs are added to the security policy. Panel names are listed in the config comment. Don't show a generated jar as the real product, or generated people as customers. |
| Opening montage scenes | `src/content/<lang>/home.js` → `intro` | Times and captions per scene. It plays once per visitor; add `?intro` to the home URL to see it again. |
| Usual end of shift | `site.config.js` → `shiftOut` | Shown on the hero time card; the work-mode switch uses it to tell daytime from evening. |
| Work-mode switch copy | `src/content/<lang>/ui.js` → `shift` | Lines by time of day, the reminder, the fake work pings. |
| Ritual music | `src/config/music.js` | Recommended Spotify / YouTube / SoundCloud / Apple Music picks, and ENDSHIFT's own playlists once they exist. Check the links with `npm run music:check`. Mood names and copy: `src/content/<lang>/ritual.js → setup.music`. |

### The product states

| `product.status` | What visitors see | Main action |
|---|---|---|
| `concept` (now) | "In development", formula shortlist, counter of founding-list signups | Join the founding list (free) |
| `preorder` | Price, deadline, dispatch window, refund terms, paid-founder counter | Become a founder → your checkout |
| `production` | Production progress | Get production updates |
| `in_stock` | Normal product page | Buy RESET → your checkout |

Moving between states is a one-line change. The build checks the rest:

```
$ npm run build
Build stopped. These would make the site say something untrue:
  ✗ product.status is "preorder" but product.price is not set.
  ✗ Preorders need batch.estimatedDispatch so founders know when it ships.
```

## Languages

- Pages exist in a language when `src/content/<lang>/<page>.js` exists. A missing page links to the English version.
- Shared interface text falls back key by key to English, so a half-translated `ui.js` still works.
- Bulgarian is at `/bg/`, with `hreflang` alternates and a separate share image. Every page exists in both languages. To add a page, write the English content file, copy it into `src/content/bg/` and translate it; templates don't change. `node scripts/check-translation.mjs bg all` checks that each translation has the same keys, lists and functions as the English file and flags Latin letters mixed into Bulgarian words.
- Values in the config that visitors read (like `contact.responseTime`, or `batch.estimatedDispatch` once set) can be a plain string or `{ en, bg }`.
- No text is baked into images, and every component allows for longer Bulgarian strings.

## Deploy

The output in `dist/` is plain files. It works on any static host.

- **Cloudflare Pages / Netlify** (recommended): build command `npm run build`, output `dist`. Both read the generated `dist/_headers` (security headers, a Content-Security-Policy generated from your config, and long-term caching for hashed assets). `netlify.toml` is included.
- **Vercel**: `vercel.json` is included (clean URLs and basic headers). Its CSP has to be added by hand from `dist/_headers` if you want it.
- Set `siteUrl` to the real domain first. It's used for canonical URLs, the sitemap, hreflang and share images.

## Before launch

`docs/LAUNCH_CHECKLIST.md` starts with a one-day plan to go live, then lists everything outside the code: domain, fonts, forms, analytics, legal review, supplement notification, health-claim review and the preorder setup. `npm run check` prints the config-side to-dos on every build.

## Accessibility

- Semantic landmarks, one `h1` per page, a skip link, and visible 3 px focus outlines.
- Targets are 44 px or larger, contrast meets WCAG AA throughout, and no information is carried by colour alone.
- `prefers-reduced-motion` removes all movement. The **Low-stim** switch in the header (saved per device) also removes the grain and softens contrast.
- The ritual can be run entirely from the keyboard (Space or Enter for Done, arrow keys for steps, Esc to pause), announces each step to screen readers, and only makes sound after you press start (and you can switch it off before or during).
